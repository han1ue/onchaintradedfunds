# Onchain Traded Funds

Onchain Traded Funds lets anyone create a fund backed by a basket of ERC-20 tokens. Each fund holds its assets in a vault and issues shares. You can trade those shares or redeem them for a proportional amount of the basket, after fees.

The creator chooses the assets, initial allocation, and fees. The application uses offchain prices and a `$1` target to calculate the starting token quantities. The vault keeps the same token list and does not rebalance as prices change. The target is not a dollar peg.

Fund shares represent a claim on one fund's basket. The separate [OTF protocol token](/token-and-fee-incentives) is used for rewards and fee buybacks.

<Callout type="warning" emoji="">
  The protocol is deployed on Robinhood Chain Testnet. It is pre-mainnet and not ready to hold value.
</Callout>
