# Onchain Traded Funds documentation

Onchain Traded Funds (OTFs) are experimental ERC-20 basket vaults. An OTF is weighted by market capitalization once, at formation, then holds a fixed ordered basket without a runtime oracle, automatic rebalance, or ongoing market-cap refresh.

<Callout type="warning" emoji="">
  The contracts are unaudited and are not production-ready. Do not deploy them to mainnet.
</Callout>

## Scope

The active protocol is separate from `launch/`, which is a prelaunch competition and is not fund governance. These documents describe the current pre-mainnet architecture and do not certify the implementation or any deployment.
