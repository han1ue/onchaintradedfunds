# Deployment addresses

The breaking fee-settlement v3 architecture is deployed on Robinhood Chain Testnet; Mainnet remains
undeployed. Earlier protocol addresses implement an incompatible fee interface and remain
unsupported.

## Robinhood Chain Mainnet

**Chain ID:** `4663` <br />
**Explorer:** [robinhoodchain.blockscout.com](https://robinhoodchain.blockscout.com/) <br />
**Status:** Not deployed

Production deployment requires explicit WETH, Uniswap V3 factory and SwapRouter02, official Uniswap
V4 PoolManager, StateView, PositionManager, Universal Router, and Permit2 addresses. Operators must
also choose the protocol multisig, team beneficiary, and maximum accepted oracle age. There is no
route-executor role. The configured team beneficiary is the initial vesting beneficiary; later
changes require nomination by the current beneficiary and explicit acceptance by its nominee.

The configured Robinhood mainnet ETH/USD AggregatorV3-compatible proxy is
[`0x78F3556b67E17Df817D51Ef5a990cDaF09E8d3A9`](https://robinhoodchain.blockscout.com/address/0x78F3556b67E17Df817D51Ef5a990cDaF09E8d3A9).
Production deployment must repeat its identity and freshness checks and configure
`ORACLE_MAX_AGE_SECONDS`. Run `pnpm oracle:verify:robinhood-mainnet` immediately before deploying.

The deployment script creates the collector before the factory, then performs one-time factory and
entry-router configuration. Vault creation registers each vault and its immutable expense
beneficiary with the collector. The router exposes the fund-share sale path only to that configured
collector; ordinary users retain the existing swap surfaces. The script records new protocol addresses only after dependency
checks, adapter approval, launch initialization, and allocation reconciliation succeed.

The application configuration retains the reviewed testnet periphery addresses and pinned runtime
hashes for PoolManager, StateView, PositionManager, Universal Router, and Permit2. The deployment is
recorded in `app/src/config/robinhood-testnet.json`; earlier incompatible protocol addresses remain
unsupported.
