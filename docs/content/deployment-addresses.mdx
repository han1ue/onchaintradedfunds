The launch manager includes the liquidity-capacity correction and uses hook mask `0x2840`. The deployed V4 adapter and collector use the testnet Universal Router's four-field tuple and clear ERC-20 and Permit2 allowances after execution. Current source targets a five-field tuple; see [deployment controls](/security#deployment-controls) before redeploying.

The launch router includes `sellOtfForEth`, which unwraps the current sale's WETH output and pays native ETH to the specified recipient.

The previous V3 adapter was [revoked](https://explorer.testnet.chain.robinhood.com/tx/0x519fe70a3ee1c911efefddd08d42e78f04a9e2aead3cb85f4dc7a6b79126b59a). Old launch positions remain onchain.

The deployment manifest, `app/src/config/robinhood-testnet.json`, records contract addresses, code hashes, receipts, launch parameters, and configuration transactions. It marks routing as ready for these deployed contracts. The protocol administrator and team beneficiary are both `0xc340D7085E321B82CF550904310EE44bae9e4CD2`.
