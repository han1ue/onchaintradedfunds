The launch manager uses hook mask `0x2840`. The V4 adapter and collector use the canonical five-field exact-input tuple and clear ERC-20 and Permit2 allowances after execution.

The launch router includes `sellOtfForEth`, which unwraps the current sale's WETH output and pays native ETH to the specified recipient.

The previous [V3 adapter](https://explorer.testnet.chain.robinhood.com/tx/0x78b6e3ece3273a8dc615aa800c2afa73de203272494193c7f833dac23814b6d3) and [V4 adapter](https://explorer.testnet.chain.robinhood.com/tx/0x9c88b68212d4803654b7b452d3770d3f49f7e44e174cefcced50990ee12ab74a) are revoked. Old launch positions remain onchain.

The deployment manifest, `app/src/config/robinhood-testnet.json`, records contract addresses, code hashes, receipts, launch parameters, and configuration transactions. It marks routing as ready for these deployed contracts. The protocol administrator and team beneficiary are both `0xc340D7085E321B82CF550904310EE44bae9e4CD2`.
