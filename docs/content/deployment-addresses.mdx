collector encode the configured Universal Router's four-field tuple and clear ERC-20 and Permit2

were configured together. Existing launch positions remain untouched onchain.

The previous V3 adapter was revoked in [this transaction](https://explorer.testnet.chain.robinhood.com/tx/0x519fe70a3ee1c911efefddd08d42e78f04a9e2aead3cb85f4dc7a6b79126b59a).
There are no compatibility aliases to the previous venue.

The manifest at app/src/config/robinhood-testnet.json records addresses, runtime hashes,
deployment receipts, launch parameters, and configuration transactions. Routing status is ready.

The four V3 contracts match the published Uniswap artifacts and their constructor arguments.

scripts/fixtures/robinhood-testnet-v3.json manifest. The position manager's NFT descriptor is zero;

TSLA/USDG, AMZN/USDG, PLTR/USDG, NFLX/USDG, and AMD/USDG are initialized and seeded at 0.3%.

The supporting WETH/USDG pool uses 0.05%; the replacement factory does not enable 0.01%.
The application's /liquidity page manages additions to these testnet markets.

Protocol WETH remains 0x33e4191705c386532ba27cBF171Db86919200B94. V3 treats it as an ERC-20. Native basket
entry and exit wrap or unwrap protocol WETH in the OTF router. The different periphery WETH9
is not substituted for it. V4, the canonical OTF/WETH pool, the launch router, collector, and
Permit2 retain the protocol WETH binding.

Live deployment and seed receipts are stored under deployments. The validation report at
contracts/TESTNET_ROUTING_VALIDATION.md separates live operations from fork execution tests.
Testnet V4 uses the existing mirror deployment with pinned runtime hashes.
