# Deployment addresses

This page lists only the canonical protocol contracts created by an OTF protocol deployment. It
does not list user-created OTFs, deployer accounts, tokens, liquidity venues, or other external
integrations. Verify the network and address before interacting with a contract. The protocol is
unaudited and pre-mainnet.

**Chain ID:** `46630`  
**Explorer:** [explorer.testnet.chain.robinhood.com](https://explorer.testnet.chain.robinhood.com/)

**Status:** Deployed; application deployment gate enabled

These addresses use the generic router/adapter architecture. Onchain verification confirms that
the factory points to the entry router, the adapter points back to that router and the configured
Uniswap V3 contracts, and the router has approved the adapter.
