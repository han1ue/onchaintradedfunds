# Deployment addresses

The protocol is deployed on Robinhood Chain Testnet. It is not deployed on Mainnet.

The recorded testnet contracts predate the H-01 fix and retain hook mask `0x2040`. The fixed launch
manager requires `0x2840` (`beforeInitialize`, `beforeAddLiquidity`, and `afterSwap`) and a new
deployment. The addresses and salts in the manifest are historical deployment records, not address
expectations for the updated bytecode. Run the deployment script with fresh artifacts to mine a
new salt and verify the resulting address before funding the launch.

The V4 adapter, collector, and application now encode the four-field tuple used by the configured
testnet Universal Router. The adapter also handles Permit2's zero-expiration semantics during
approval cleanup. These corrections require fresh protocol contracts. The testnet deployment
script rejects dependency addresses or runtime hashes that differ from the routing validation
manifest; mainnet addresses cannot substitute for contracts on this testnet.

## Robinhood Chain Mainnet

**Chain ID:** `4663` <br />
**Explorer:** [explorer.chain.robinhood.com](https://explorer.chain.robinhood.com/) <br />
**Status:** Configuration required

The repository records the verified Robinhood ETH/USD oracle at `0x78F3556b67E17Df817D51Ef5a990cDaF09E8d3A9`. This is an external dependency, not a protocol deployment.

A production deployment must provide WETH, Uniswap V3 Factory and SwapRouter02, Uniswap V4 PoolManager, StateView, PositionManager and Universal Router, Permit2, oracle maximum age, protocol multisig, and team beneficiary. Deployment tooling must verify the selected dependencies and reconcile the full one-billion-OTF allocation before writing application configuration.

The application reads these addresses from `app/src/config/robinhood-testnet.json`. That manifest also records deployment and setup transaction hashes, block numbers, gas usage, approved adapters, launch parameters, and the pinned hashes for external V4 contracts.

This deployment uses the 15 ETH initialization and nominal 135 ETH graduation target. Its OTF address sorts after WETH, so the deployed pool uses the currency1 vectors.

The deployment completed its dependency, launch-parameter, role, allowance, and token-allocation checks before writing the manifest. The configured protocol administrator and team beneficiary are both `0xc340D7085E321B82CF550904310EE44bae9e4CD2`.

Testnet uses an unofficial V4 mirror. Matching the configured bytecode hashes confirms the reviewed runtime bytes at the selected addresses; it does not make that deployment official or remove its operational risk.
