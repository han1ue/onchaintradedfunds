Protocol WETH is used for fund settlement, swaps, the launch router, and buybacks. The separate V3 periphery WETH9 binding does not replace it. The V3 position manager has no NFT descriptor: ownership and liquidity operations work, but NFT `tokenURI` rendering is unavailable.

The existing USDG pairs with TSLA, AMZN, PLTR, NFLX, and AMD charge 0.3%. WETH/USDG uses 0.05%. The application's `/liquidity` page manages liquidity additions. Asset and pool records are scoped to chain 46630 in the database registry.

The configuration is in `app/src/config/robinhood-testnet.json`. Run `corepack pnpm contracts:verify:testnet-routing` to check current dependencies, adapter approval, vault bindings, and registered pools.

## Robinhood Chain Mainnet

Chain ID: 4663. Protocol status: not deployed.

The configured external ETH/USD oracle is `0x78F3556b67E17Df817D51Ef5a990cDaF09E8d3A9`.

Mainnet execution requires the protocol contracts and their bindings. The maintained fork suite verifies the configured external venues and rehearses protocol operations locally. Testnet results do not establish production readiness.
