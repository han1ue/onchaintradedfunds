# Onchain Traded Funds documentation

The documentation extends the app's “Calm Exchange” identity into a Read surface built with Nextra.

## Visual system

- Deep slate and blue-black surfaces use the existing app palette; teal marks active navigation, links, focus, and confirmed paths.
- Workhorse system sans typography and a 74-character article measure prioritize comprehension over promotion.
- Thin ledger rules and adjacent surface tones establish hierarchy without turning the site into a grid of cards.
- The compact OTF mark, restrained radii, explicit focus rings, themed selection, and scrollbars carry the brand into browser-native surfaces.

## Information architecture

- The documentation index orients readers and links to the protocol overview, normative security specification, threat model, and token/fee policy.
- Pagefind search, sidebar navigation, page outlines, previous/next navigation, GitHub, and the main application remain available from the shared shell.

## Constraints

- Technical source documents remain factual and are moved into the Nextra content collection without rewriting their claims.
- The site defaults to dark mode but retains an accessible light theme.
- Motion is limited to Nextra interaction feedback and is effectively disabled when reduced motion is requested.
